# Склад техники (WarehouseTech)

Тестовое задание. Web-приложение для учета техники на складе.

## Стек технологий
* **Backend/Frontend:** C#, ASP.NET Core (Blazor Web App - Server Interactive), SignalR.
* **База данных:** PostgreSQL, Entity Framework Core.
* **Инфраструктура:** Docker, Docker Compose.

## Как запустить проект

Проект полностью упакован в Docker. Для запуска вам потребуется установленный Docker Desktop.

1. Откройте терминал в корневой папке проекта (где находится файл `docker-compose.yml`).
2. Выполните команду:
   ```bash
   docker-compose up --build
3. После сборки откройте в браузере: http://localhost:8080
   База данных PostgreSQL запускается автоматически, миграции применяются при старте приложения.

## Функционал
* **Страница «Справочники»: добавление, редактирование, удаление типов техники и производителей.

* **Страница «Позиции»: таблица с оборудованием, фильтрация (поиск, тип, производитель, цена), создание и редактирование через единое модальное окно, добавление новой страны поставки на лету, загрузка фотографий.

* **SignalR: обновление списка позиций в реальном времени для всех пользователей.
